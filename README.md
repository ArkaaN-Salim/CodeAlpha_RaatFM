# RAAT FM — CodeAlpha Task 4

A cinematic, responsive JavaScript music player inspired by the atmosphere of late-night radio. Built for the CodeAlpha Frontend Development internship.

## Features
- HTML/CSS music-player interface
- JavaScript play / pause / previous / next controls
- Song title, artist and duration
- Interactive progress/seek bar
- Volume control with in-player mute/unmute toggle
- Playlist with track selection
- Autoplay / automatic next-track playback toggle
- Responsive desktop and mobile layout
- Keyboard controls: Space, Left/Right arrows, Up/Down volume
- Glassmorphism controls and RAAT FM visual identity
- Live clock and front-end demo online counter

## Run locally
Open the project in VS Code and use Live Server, then open `index.html` through the local server.

The included MP3 files are user-provided commercial recordings. Before publishing the audio files publicly (for example through GitHub Pages), replace them with audio you have permission to distribute or use properly licensed/royalty-free tracks.
